# Pulsar TK app

Phone app prototype for the Pulsar Devices task keeper. One web page that
talks to the device over Bluetooth (Web Bluetooth).

- **iPhone:** open the page in the free **Bluefy** browser (Safari has no
  Web Bluetooth).
- **Preview without the device:** add `?mock` to the address.

The source of truth lives in the private `task-keeper` repo
(`phone-app/index.html`); this repo only publishes it with GitHub Pages.
